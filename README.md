# Suwayhib — in the browser

A Qur'an recitation companion that follows you word by word, running entirely in your
browser: **https://faruqhfetech.github.io/suwayhib-web/**

This repository holds the built site only (from `inweb/build.py`).

- Phoneme model: Quran-Lab's streaming Zipformer, under the Quran-Lab No-Profit License 1.2
  (`sherpa/MODEL-LICENSE.txt`). Free to use; never for sale, behind a paywall or with ads.
- Automatic feedback can be wrong; it does not replace a qualified teacher.
